## Sobre

Site da **CR Jardinagem**, empresa de corte de grama, poda e manutenção de jardins em Curitiba. O objetivo é levar o cliente do Google até o WhatsApp no menor número de passos possível, com o site divulgado em campanhas do Google Ads.

## Seções

| Seção | Conteúdo |
|---|---|
| **Início** | Chamada principal e botão de orçamento pelo WhatsApp |
| **Serviços** | Corte de grama, poda de cerca viva, arbustos e árvores, limpeza de jardim e de pavers |
| **Por que escolher** | Atendimento direto com os donos, pontualidade, capricho e preço sem surpresa |
| **Antes e depois** | Galeria com fotos dos serviços, navegável por toque no celular |
| **Curitiba** | Região atendida |
| **Como funciona** | Chamar no WhatsApp, receber o orçamento e ter o serviço feito |
| **Perguntas frequentes** | Dúvidas comuns em blocos que abrem e fecham |
| **Contato** | Chamada final para o WhatsApp |

## Destaques técnicos

- **Arquivo único**: HTML, CSS, JavaScript e imagens no mesmo arquivo, sem framework e sem dependências.
- **Responsivo**: pensado primeiro para o celular, onde vem a maior parte dos clientes.
- **SEO local**: título e descrição otimizados, Open Graph e dados estruturados (`LocalBusiness` em JSON-LD).
- **Medição de conversões**: Google Tag Manager registra cada clique no WhatsApp, para acompanhar os resultados do Google Ads.
- **Animações leves** com `IntersectionObserver`, desligadas para quem prefere menos movimento (`prefers-reduced-motion`).
- **Política de privacidade** em janela própria, com o que é coletado, cookies e direitos do usuário.

## Como rodar

Não precisa instalar nada. Abra o `index.html` no navegador.

Para publicar, envie o arquivo para qualquer hospedagem estática, como Render, GitHub Pages ou Netlify.
